# مشخصات فنی و معماری موتور هوشمند شکار پروژه (Job Hunter)

> **تاریخ:** 2026-09-11  
> **نسخه:** 1.0.0  
> **هدف سیستم:** پایش هوشمند پلتفرم‌های فریلنسری، فیلتر و ارزش‌گذاری پروژه‌ها بر مبنای نرخ بازگشت زمان (ROI)، تولید خودکار معماری و پروپوزال، گزارش‌دهی دوگانه (تلگرام + مارک‌داون) و ثبت خودکار یا نیمه‌خودکار فرم‌های درخواست با مرورگر.

---

## ۱. اهداف و چشم‌انداز

این سیستم تلفیقی از سرعت و پایش سبک پروژه `freelance-hunter` و عمق تحلیل، تطابق شغلی و پایپ‌لاین‌های ارزیابی پروژه `ai-job-search` است. هدف کلیدی، کاهش زمان جستجو و ارسال پیشنهاد از چند ساعت در روز به کمتر از ۱۵ دقیقه با بالاترین نرخ تبدیل و دقت فنی است.

---

## ۲. اسکوپ‌های هدف و کف مبالغ

پروژه‌های ورودی بر اساس ۶ حوزه تخصصی با خروجی تضمین‌شده پالایش می‌شوند:

| ردیف | حوزه تخصصی (Scope) | پشته پیشنهادی / ابزار | حداقل بودجه (تومان / دلار) |
| :---: | :--- | :--- | :--- |
| ۱ | **ربات‌های تلگرام و بله (Bots)** | Python (aiogram), Bale API, Telegram Bot API | ۱,۵۰۰,۰۰۰ تومان / ۲۰$ |
| ۲ | **اتوماسیون فرایندها (Automation)** | n8n, Python, Webhooks | ۲,۰۰۰,۰۰۰ تومان / ۳۰$ |
| ۳ | **ترجمه تخصصی و دانشگاهی (Translation)** | موتور ترجمه علمی (scientific-fa-translation) | ۵۰۰,۰۰۰ تومان / ۱۰$ |
| ۴ | **تمیزکاری و تحلیل اکسل (Excel & Data)** | Python (openpyxl, pandas), VBA | ۵۰۰,۰۰۰ تومان / ۱۰$ |
| ۵ | **وب‌اسکرپینگ و استخراج داده (Scraping)** | Playwright, BeautifulSoup, Camoufox | ۱,۵۰۰,۰۰۰ تومان / ۲۰$ |
| ۶ | **توسعه اسکریپت و API (Scripting)** | FastAPI, Requests, SQLite | ۲,۰۰۰,۰۰۰ تومان / ۳۰$ |

> *تبصره:* حوزه تبدیل اسناد و فرمت‌بندی PDF/Word طبق تصمیم اولیه تا ارتقای دقت خروجی موقتاً غیرفعال (Disabled) می‌ماند.

## ۳. پلتفرم‌های هدف و متد استخراج

1. **پونیشا (Ponisha):** استخراج سبک داده‌های خام JSON از اسکریپت `__NEXT_DATA__` در صفحه جستجو.
2. **پارسکدرز (Parscoders):** اسکرپ سریع ساختار HTML آگهی‌ها با کتابخانه `urllib` / `requests`.
3. **Freelancer.com:** استفاده از Public API رسمی بدون نیاز به کلید برای پروژه‌های فعال با کلیدواژه‌های مشخص.
4. **پلتفرم‌های تکمیلی (Guru, LaborX):** اسکرپرهای سبک HTML برای استخراج موقعیت‌های ارزی دلاری و رمزارزی.

## ۴. چرخه حیات داده‌ها و معماری سیستم (Data Pipeline)

```
[پیکربندی: config.yaml]
         │
         ▼
[۱. اسکرپرهای سبک HTTP] ──(کوکی‌های سشن مرورگر)
         │
         ▼
[۲. فیلتر امنیتی و فیلتر اسکم] ──(رد کردن موارد مشکوک یا بودجه زیر کف)
         │
         ▼
[۳. موتور ارزیابی ارزش و ROI] ──(تفکیک به Tier A / Tier B / Tier C)
         │
         ▼
[۴. موتور معمار AI (Architect)]
    ├── تعیین قیمت و روز تحویل بهینه
    ├── نگارش پروپوزال فنی و اختصاصی
    ├── پشته نرم‌افزاری دقیق
    └── تدوین رودمپ فنی ۳ الی ۴ مرحله‌ای
         │
         ▼
[۵. ذخیره در دیتابیس SQLite] (data/hunter.db)
         │
         ▼
[۶. گزارش‌دهی دوگانه]
    ├── فایل جامع گزارش روزانه (reports/YYYY-MM-DD.md)
    └── پیام تلگرام ساختاریافته همراه با ID رهگیری و دکمه‌های شیشه‌ای
         │
         ▼
[۷. تکمیل فرم پروژه با Playwright]
    ├── از طریق ترمینال: `python run.py apply <id>`
    └── از طریق تلگرام: لمس کلید تایید در ربات
```

## ۵. مدیریت سشن‌ها و امنیت احراز هویت

* یک ماژول کمکی به نام `auth_helper.py` وجود دارد که با اجرای `python run.py auth <platform>` یک پنجره مرورگر باز می‌کند تا کاربر وارد حساب خود شود.
* وضعیت ذخیره‌شده سشن (`storage_state.json`) در مسیر امن `data/sessions/` نگهداری می‌شود.
* در زمان ثبت پیشنهاد (`apply`)، مرورگر به صورت پیش‌فرض در حالت دارای رابط گرافیکی (Headed) باز می‌شود و فرم را پر می‌کند، اما برای جلوگیری از هدررفت بودجه یا ارسال اشتباه، پیش‌نمایش نهایی را تا تایید چشم کاربر متوقف نگه می‌دارد (Human-in-the-loop).

---

## ۶. مشخصات رابط کاربری و دستورات

### الف) دستورات خط فرمان (CLI)
* `python run.py scan [--mock] [--dry-run]`: اسکن پلتفرم‌ها، تحلیل AI، ذخیره در دیتابیس و تولید گزارش‌ها.
* `python run.py list [--tier A]`: نمایش لیست پروژه‌های فعال و بررسی‌شده.
* `python run.py apply <job_id>`: باز کردن خودکار فرم با مرورگر و تزریق مشخصات پیشنهاد.
* `python run.py auth <platform>`: ذخیره سشن و کوکی‌های ورود پلتفرم مورد نظر.
* `python run.py bot`: اجرای سرویس گوش‌به‌زنگ تلگرام برای تعاملات از راه دور.

### ب) رابط کاربری تلگرام (Telegram Interface)
* ارسال آنی پروژه‌های رده Tier A با جزئیات کامل، رودمپ و پیش‌نویس متن.
* استفاده از دکمه‌های درون پیام (Inline Keyboard) برای انجام عملیات:
  * `[ ✅ تایید و پر کردن فرم ]`
  * `[ ✏️ تغییر قیمت / متن ]`
  * `[ ❌ رد کردن / عدم تمایل ]`

## ۸. معیارهای موفقیت و پایداری (Acceptance Criteria)

1. اسکن تمام سایت‌های فعال در کمتر از ۳۰ ثانیه بدون انسداد یا مسدود شدن آی‌پی.
2. عدم ارسال پیشنهاد برای پروژه‌های تکراری با مکانیزم شناسه یکتای دیتابیس (`job_hash`).
3. تولید پروپوزال اختصاصی و رودمپ گام‌به‌گام برای پروژه‌های دارای رتبه بالا (Tier A).
4. باز شدن بدون خطای فرم در Playwright با سشن از پیش ذخیره‌شده و پر شدن دقیق فیلدهای قیمت، روز و متن.
