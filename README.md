# 🏹 OmniHunter (شکارچی هوشمند پروژه‌ها)

> فریم‌ورک خودکار و سبک برای پایش پلتفرم‌های فریلنسری، پالایش پروژه‌ها بر مبنای نرخ بازگشت زمان (ROI)، تولید معماری و پروپوزال اختصاصی، گزارش‌دهی دوگانه (تلگرام + مارک‌داون) و ثبت فرم پیشنهاد با تایید انسانی.

---

## 🌟 قابلیت‌های کلیدی

1. **پایش چند پلتفرمه و فوق‌سریع (Scraping):**
   - **پونیشا (Ponisha):** استخراج مستقیم از `__NEXT_DATA__` بدون نیاز به رندر سنگین مرورگر.
   - **پارسکدرز (Parscoders):** اسکرپ سبک ساختار HTML با تبدیل هوشمند ارقام و بودجه.
   - **فریلنسر (Freelancer.com):** استفاده مستقیم از پابلیک API رسمی بدون نیاز به API Key.
   - **مدیریت نشست (Cookies/Auth):** امکان تزریق سشن‌های ذخیره‌شده Playwright به درخواست‌های HTTP.

2. **غربالگری، فیلتر اسکم و رتبه‌بندی ROI (Triage):**
   - رد خودکار پروژه‌های کلاهبرداری یا مشکوک (بیعانه، پرداخت اول، تست رایگان و...).
   - پایش ۶ اسکوپ تخصصی:
     - 🤖 **ربات‌های تلگرام و بله** (حداقل ۱.۵ میلیون تومان / ۲۰ دلار)
     - ⚡ **اتوماسیون فرایندها (n8n و وب‌هوک)** (حداقل ۱.۵ میلیون تومان / ۲۰ دلار)
     - 📚 **ترجمه تخصصی و دانشگاهی** (حداقل ۵۰۰ هزار تومان / ۱۰ دلار)
     - 📊 **اکسل، ماکرو و تمیزکاری داده** (حداقل ۵۰۰ هزار تومان / ۱۰ دلار)
     - 🕷 **وب‌اسکرپینگ و استخراج داده** (حداقل ۱.۵ میلیون تومان / ۲۰ دلار)
     - 🐍 **اسکریپت‌نویسی و وب‌سرویس پایتون** (حداقل ۱.۵ میلیون تومان / ۲۰ دلار)
   - محاسبه نرخ ارزش زمانی به کار (ROI) و دسته‌بندی در رده‌های **Tier A** (عالی)، **Tier B** (متوسط) و **Tier C** (ردشده).

3. **معمار هوش مصنوعی (AI Architect):**
   - تخمین هوشمند قیمت پیشنهادی و روزهای تحویل.
   - پیشنهاد پشته فنی دقیق (Tech Stack).
   - تدوین رودمپ فنی ۳ الی ۴ مرحله‌ای برای تحویل مطمئن کار.
   - نگارش پروپوزال اختصاصی بدون کلیشه‌های تکراری هوش مصنوعی.

4. **گزارش‌دهی دوگانه (Dual Reporting):**
   - تولید فایل گزارش جامع روزانه در مسیر `reports/YYYY-MM-DD.md` (با تجمیع تمام اسکن‌های طول روز).
   - ارسال آنی کارت‌های پروژه به تلگرام همراه با شناسه اختصاصی و دکمه‌های شیشه‌ای.

5. **ثبت فرم با مرورگر و مکانیزم ایمنی تایید دستی (Human-in-the-Loop Form Filler):**
   - باز شدن مرورگر Playwright و پر شدن فیلدهای قیمت، روز و متن پیشنهاد.
   - **مکانیزم ایمنی:** سیستم پیش از هرگونه کلیک روی دکمه ارسال نهایی، در ترمینال متوقف شده و منتظر تایید چشمی و کلید اینتر شما می‌ماند تا هیچ خطایی رخ ندهد.

6. **رویکرد توسعه آتی (ربات تعاملی دوطرفه تلگرام):**
   - *نکته معماری:* سیستم برای تعامل کامل دوطرفه از بستر تلگرام پایه‌ریزی شده است. زیرساخت هندلر دکمه‌های اینلاین (`apply:<id>` و `reject:<id>`) پیاده‌سازی شده و امکان گسترش آن برای مدیریت مستقیم و کنترل از راه دور مرورگر از طریق گوشی تلفن همراه در نسخه‌های آتی مهیا است.

## 🚀 راهنمای نصب و راه‌اندازی

### ۱. پیش‌نیازها
- پایتون نسخه 3.10 یا بالاتر
- نصب وابستگی‌ها:
  ```bash
  pip install -r requirements.txt
  playwright install chromium
  ```

### ۲. پیکربندی (`config.yaml`)
توکن ربات تلگرام و `chat_id` خود را در فایل `config.yaml` قرار دهید (یا از طریق متغیرهای محیطی `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` تنظیم کنید).

## 💻 نحوه استفاده از دستورات CLI

### ۱. اسکن پروژه‌ها (Scan)
```bash
# اجرای اسکن زنده روی پلتفرم‌ها:
python run.py scan

# اجرای اسکن آزمایشی با داده‌های موک (بدون نیاز به اینترنت):
python run.py scan --mock

# اجرای اسکن و ارسال آنی پروژه‌های رده Tier A به تلگرام:
python run.py scan --notify

# اسکن بدون ذخیره‌سازی در دیتابیس (Dry-Run):
python run.py scan --dry-run
```

### ۲. مشاهده لیست پروژه‌ها (List)
```bash
# مشاهده پروژه‌های پیشنهادی و طلایی (Tier A):
python run.py list --tier A

# مشاهده پروژه‌های جدید و اقدام‌نشده:
python run.py list --status new --limit 10
```

### ۳. آماده‌سازی و ارسال پیشنهاد با مرورگر (Apply)
```bash
# باز کردن فرم در مرورگر، پر کردن مقادیر در حالت پیش‌نمایش (بدون ارسال):
python run.py apply 1

# باز کردن فرم در مرورگر برای ارسال نهایی (همراه با تاییدیه دستی در ترمینال):
python run.py apply 1 --submit
```

### ۴. لاگین و ذخیره سشن پلتفرم‌ها (Auth)
```bash
# لاگین در پلتفرم مورد نظر برای ذخیره دائمی نشست و کوکی‌ها:
python run.py auth ponisha
python run.py auth parscoders
python run.py auth freelancer
```

### ۵. اجرای شنونده دکمه‌های تلگرام (Bot Listener)
```bash
# بررسی یک‌باره کلیک دکمه‌ها:
python run.py bot --once

# اجرای مداوم شنونده تلگرام:
python run.py bot
```
